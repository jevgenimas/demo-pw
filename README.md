# **Project "Demo Playwright"**

## Description:

This project contains Playwright tests on the following topics:
1. Login
2. Checkout by filling in the username and email fields and clicking the order button

## Configure:
1. Clone the repository.
2. Install dependencies: `npm install`
3. Install the Faker.js library: `npm install @faker-js/faker`
4. Create a .env file in the root directory with the following content: APP_URL=https://fe-delivery.tallinn-learning.ee/

## Run tests:

Run all tests: `npx playwright test`
